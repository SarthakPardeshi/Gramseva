# GramSeva 🌾

**GramSeva** is a digital bridge designed to connect villagers directly with government services and information. This full-stack application streamlines the communication process, ensuring that rural communities stay informed about local notices and government schemes through a transparent, accessible platform.

---

## 🔗 Live Links

* **User Platform:** [GramSeva Web App](https://gramseva-seven.vercel.app/)
* **Admin Dashboard:** [GramSeva Admin Panel](https://admin-ashy-one-14.vercel.app/notices)

---

## ✨ Key Features

### 👤 User Portal (Villagers)
* **Notice Board:** View real-time updates and official announcements from local authorities.
* **Scheme Awareness:** Easy access to information regarding state and central government welfare schemes.
* **Responsive Design:** Optimized for mobile devices to ensure accessibility in areas with varying tech infrastructure.

### 🔑 Admin Portal (Government Officials)
* **Dynamic Content Management:** Create, edit, and delete notices instantly.
* **Centralized Database:** Manage all public-facing information from a secure, authenticated dashboard.
* **Real-time Synchronization:** Changes made in the admin panel reflect immediately on the main user site.

---

## 🛠 Tech Stack

Built using the **MERN Stack** for high performance and scalability:

* **Frontend:** React.js (User & Admin interfaces)
* **Styling:** Tailwind CSS / CSS3
* **Backend:** Node.js & Express.js
* **Database:** MongoDB
* **Deployment:** Vercel
